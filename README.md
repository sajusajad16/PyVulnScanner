## 📦 Installation

```bash
git clone https://github.com/sajusajad16/PyVulnScanner.git
cd PyVulnScanner/scanner
```

### 🔹 Create Virtual Environment

```bash
python3 -m venv venv
source ../venv/bin/activate
```

### 🔹 Install Requirements

```bash
pip install -r ../ReconX/requirements.txt
```
